# Robotic Dog Project

This repository contains two separate deliverables related to robotic dog projects. These two parts are independent of each other and are not related to the same design.

## Part 1: Design & Specifications Report 

This part contains a written report covering the specifications and design of a robotic dog product.

**Contents:**
- Product overview
- Design requirements
- Technical specifications
- Design details and justification

**File:** `Robotic_Dog_Design_Report.pdf`

## Part 2: Exploded View (Robotic Dog)

This part contains an exploded view of a different robotic dog model. the assembly was done on solidworks 

**Contents:**
- Exploded view images
- Exploded view video
